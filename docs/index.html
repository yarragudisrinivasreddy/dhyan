How it works

Full agent loop

Not just analyze-and-show. Dhyan closes the loop with acknowledgment and a human handoff boundary.

Sense

Webcam + presence detection. Skip dark or empty frames.

Decide

Gemma 4 scores fatigue, posture, tips, and urgency.

Act

Sounds, dashboard insight, and OS notifications.

Check

Acknowledge the alert or hand off after 3× HIGH.

Privacy promise

Zero cloud. Open source.

Dhyan is built local-first for people who will not send face data to a vendor API.

  • Frames stay on localhost
  • Gemma 4 inference via LM Studio on-device
  • In-memory session state only
  • MIT licensed
Features

Built for long screen days

Get started

Install in minutes

Clone & run Flask
uv pip install -r requirements.txt && uv run python app.py
Start LM Studio
Load google/gemma-4-e4b · server on port 1234
Load the Chrome extension
chrome://extensions → Developer Mode → Load unpacked → extension/
