The agent loop

01 · SENSE

Sense

Webcam captures a frame. Brightness and motion are checked first — dark frames and empty desks are skipped automatically. Only when you're present does analysis begin.

02 · DECIDE

Decide

Gemma 4 e4b running locally on LM Studio analyzes posture, facial tension, and eye fatigue. Your session trend and mobile phone usage are injected as context.

03 · ACT

Act

A wellness insight appears in the dashboard. Sound alerts fire based on fatigue level. Chrome notifications appear even when the browser is minimized.

04 · CHECK

Check

Dhyan waits for your acknowledgment. After 3 consecutive high-fatigue readings, the agent steps back and hands control to you — the human handoff boundary.

Everything you need. Nothing you don't.

01

Zero cloud

Webcam frames go to localhost only. Gemma 4 runs on your machine. Nothing is logged, stored, or transmitted.

02

Battery optimized

Presence detection at 160×120 before full capture at 480×360. Intelligent skipping cuts wasted compute by ~40%.

03

OS notifications

Chrome Extension fires native system notifications — visible even when your browser is minimized or behind other windows.

04

Mobile awareness

Optional phone pickup tracking. Dhyan adds dual-screen fatigue context when you switch between your laptop and phone.

05

Posture reference

Three posture guides (ideal, forward lean, slouch) stay visible so you can self-correct in real time.

06

Human handoff

After 3 consecutive high-fatigue readings, Dhyan pauses itself and asks you to take a real break. The agent knows its limits.

Your camera. Your data. Your machine.

Most wellness tools send your webcam feed to a remote server for analysis. Dhyan does the opposite: Gemma 4 e4b runs entirely on your device via LM Studio. Your frames never leave localhost.

Session data is kept in memory only — nothing written to disk. No account. No telemetry. No analytics. When you close the app, all data is gone.

The Chrome Extension talks exclusively to localhost:5000. MIT-licensed and auditable by anyone.

  • No account required
  • No telemetry or analytics
  • MIT licensed — audit the code

Up and running in 5 minutes

Web Dashboard

01

Install LM Studio → load google/gemma-4-e4b → start server on :1234

02

Clone the repository

git clone https://github.com/yarragudisrinivasreddy/dhyan.git
03

Install dependencies

uv pip install -r requirements.txt
04

Start the app → open localhost:5000

uv run python app.py

Chrome Extension

01

Clone the repo (same as above)

02

Open chrome://extensions

chrome://extensions
03

Enable Developer Mode → Load unpacked → select extension/ folder

04

Pin Dhyan · click ◈ icon · Start Agent
